## Entry point

**Signal type:** Scheduled / time-based event

Transcript data from P0-P3 Jira or Slack uploaded to the "Raw Input" column in Juno (the dashboard built in M1) per the PRD defined schedule.

**What they see instantly**

"Transcript being generated" appears with a "% completion" until finished to signal that the agent is working.  

## The flow

1. 1. RAG retrieval over the RocketShip Strategy One-Pager (M2 deliverable) + last 30 days of Slack #voice-of-customer + Jira tickets under Customer Service Intake pool. Top-K = 8 retrieval segments per prioritization run.
2. Categorization logic, cited evidence gathered.
3. Risk + alignment categorized and prioritized, and conflicting evidence is flagged explicitly.
4. Confidence check, hand off to human PM if confidence is below 70% on any P0 risk.
2. "Scanning Strategy One-Pager…" → "Categorizing transcript with common themes and patterns in the dates/times reported" → "Synthesizing priorities + drafting PRD section…"
3. Single Path (Strategy loaded) → grounded prioritization with citations.


## AI moments

**Placement:** Full-Page Canvas

8 retrieval segments per prioritization, each with at least one piece of evidence (ticket ID, Slack permalink), categorization includes cited reason. The PRD draft renders citations inline as footnotes the PM can click to verify. PRD draft in column 3 references the cards.

Value prop = augmentation (M2). The PM is the validator, they edit and approve, not create from blank. Inline keeps them in flow with the raw transcript on the left.

## Fallbacks

**Kill switch**

Every Insight Card has a "Manual Override" button → re-tag P0-P3, edit the rationale, or mark "closed". PRD blocks are individually editable + regenerable. When manually marked "closed" references to those are removed from PRD column. 

**Training signal**

Manual demote → logged as "strategic-alignment correction." 3+ similar overrides → flag the strategic pillar as ambiguous + tighten retrieval.

**Fail-safe**

If RAG returns conflicting transcripts → Juno tags the card "For PM Review" + amber warning. Never invents an alignment. PM can promote manually or send back for clarification.
