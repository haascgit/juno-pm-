## Goal

Recap weekly information about each customers watchlists.

**Primary actor:** Agent (autonomous)

## Trigger

Weekly per schedule outlined 6pm ET on Fridays => triggers READ queries a) Company watchlist database NASDAQ symbols b) GraphQL market data sbfinancials c) Pubedit database article symbol.

## Steps & tools

**Pattern:** ReAct (single-agent reason-act-observe loop)

| Step | Action | Tool / model | Guardrail |
|---|---|---|---|
| 1 | RAG retrieval over Watchlist Recaps Strategy One-Pager + run READ queries | Watchlist database (lists query), read-only | Agent can READ query data + write and push JSON Watchlist recaps dd/mm/yyyy (summary generated files) Agent CANNOT edit any database records to Watchlist database, GraphQL, or Pubedit database.  |
| 2 | Synthesize a) unique symbol set b) data patterns per symbols c) associated news | GraphQL market data (sbfinancials query), read-only |  |
| 3 | Draft recaps summaries per watchlist id for symbols listed. | Pubedit database (article query), read-only |  |
| 4 | Cite headlines referenced in recaps with links. | _ |  |
| 5 | Push JSON file for weekly recap with record rows per watchlist id. | _ |  |

**Schemas**

- Watchlist database (lookup watchlist.id, symbols)
- GraphQL market data (lookup data sbfinancials query)
- Pubedit database article (symbol, date, headline, url)


**Memory (in or out of scope)**

- **Episodic:** In-scope, query results, symbol lists, headlines per symbol. Lifetime: end of run.
- **Semantic:** In-scope, Watchlist Recaps file from NASDAQ Common Stocks + Natural language summary recaps per watchlist record + cited source headlines. Lifetime: 7 day persisted, weekly generated. Out of scope, persisting historical summaries beyond 7 day window.
- **Working:** In-scope, query list symbols data per watchlist id, query symbol price and earnings moves, query articles by symbol, generate text summaries. Held in working context only.
- **External:** Watchlist database (read), GraphQL market data sbfinancials (read), Pubedit database article symbol (read), weekly_recap_dd/mm/yyyy JSON (write).

## Human-in-the-loop

The number of "No Recap" records per week generated back => reviewed by PM to review for query logic edits to tighten future weekly retrievals.

## Success & failure

- **Done when:** - Success: Watchlist Recap JSON file pushed within 24 hours of scheduled start.
- Failure: "No Recaps" file generated.
- Escalation: >30% record rows recorded "No Recap" → hand to PM.
- Timeout: 90s wall clock → abort with no output.
- **Fails safe when:** Agent can READ query data + write and push JSON Watchlist recaps dd/mm/yyyy (summary generated files) Agent CANNOT edit any database records to Watchlist database, GraphQL, or Pubedit database.
