# Eval Stack · Watchlist Recaps Weekly

_Module 6. Generated by `M6 - Eval Stack Designer.html`. Paste over `06-evals/eval-stack.md`._

## What "good" means

<20% thumbs down per week; customer regenerate rate on subsequent week >90%

- Active: click to view weekly recap, and provide thumbs up/down to signal usefulness back to the system.
- Passive: daily report generated for thumbs down recaps, citing watchlist recap record for PM review.

## The stack

| Layer | Evaluator | What it catches | Threshold / gate |
|---|---|---|---|
| Code-based | Automated checks · cadence: Weekly file generation + daily thumbs down report · owner: CI fails the file generation. Eng owns format/delivery to frontend web page. PM owns the accuracy bar. | - LLM-judge: data accuracy + tone - Citation check: every article links to a real headline - PII filter: must redact customer names/IDs - Refusal check: empty recap => refuse to push JSON and escalate to live PM | >=90% golden-set accuracy; 100% data/citation/refusal pass |
| LLM-as-judge | Automated assessment on the golden set | Silent wrong outputs at the long tail | >=90% golden-set accuracy; 100% data/citation/refusal pass |
| Human | 06-evals/human-rubric.md · 2 graders + PM tiebreak per disagreement protocol · cadence: Weekly batch (Friday 6pm ET schedule) + Daily thumbs down report | - Single Watchlist Recap summary JSON output / week - 100% of thumbs down daily reports reviewed - Stratified across accuracy and usefulness buckets (high / mid / low) | >=4.0/5 mean across accuracy + safety; 0 critical safety fails |

## Golden set

- 300 anonymized recap summary usefulness reviews with query and/or language learning optimizations suggested
- Versioned in 06-evals/golden-set/
- Refresh weekly and after each run

## Release gate

**Hard gates (auto-block):**

- 0% PII leakage (auto-block)
- 0 critical safety fails on the human-eval layer
- Data accuracy fail => block

**Soft gates (PM sign-off):**

- P99 latency >60s requires PM justification + eng lead approval

**User-feedback layer (online):** cadence Per request + daily aggregate; owner PM owns daily reviews; auto-Slack on >=30% thumbs down after first +100 opens..
